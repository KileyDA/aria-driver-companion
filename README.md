# ARIA DRIVER COMPANION 
# Project Overview
ARIA Driver Companion is an embedded prototype designed to support truck driver alertness, journey-state awareness, and friendly interaction during long drives.

Long-haul and commercial truck drivers often work in demanding conditions involving long hours, repetitive routes, fatigue, isolation, and reduced stimulation. ARIA explores how a small embodied companion system can provide supportive prompts, log simple driver responses, and make driver-state interaction feel more natural and less intrusive than conventional monitoring alerts.

The prototype uses a Raspberry Pi, Picoh robot, audio prompts, and driver input logging to explore how a physical companion interface could support safer and more engaging driving experiences.

# Core Idea
ARIA is not designed to replace certified driver monitoring or vehicle safety systems. Instead, it explores how an embodied companion interface could add a more supportive interaction layer.

The system focuses on:

- Short, non-distracting voice prompts
- Simple driver response input
- Response logging for later review
- Companion-style interaction through Picoh
- A human-centred approach to driver alertness support

## Safety and Privacy Notes

ARIA is a prototype exploration and is not a certified vehicle safety system.

Any driver feedback, interview notes, recordings, or personal information will be kept private and will not be uploaded to this public repository without permission.
